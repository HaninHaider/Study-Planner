# University Study Planner

A web-based study planner developed using HTML, CSS and JavaScript to help university students organise their workload, keep track of deadlines and monitor their academic progress.

I originally developed this project as part of my first-year **Web Development I (4322COMP)** coursework at Liverpool John Moores University.

After submitting the coursework, I decided to continue working on the application in my own time. I found web development particularly interesting and wanted to challenge myself to build on what I had learned, explore additional features and improve my programming skills beyond the university requirements.

## Features

- **Interactive Calendar:** Displays coursework deadlines, exams and revision tasks in a calendar format.
- **Task Management:** Allows users to add revision tasks, set deadlines and track completed work.
- **Deadline Tracking:** Highlights overdue tasks and upcoming deadlines to help students manage their workload.
- **Grade Tracking:** Allows students to enter assessment marks and monitor their academic performance.
- **Grade Goals:** Users can set a target classification, such as a 2:1 or First, and track their progress towards it.
- **Study Focus Timer:** A countdown timer to help students manage focused study sessions.
- **Responsive Design:** Designed to work across different screen sizes.

## Technologies Used

- HTML5 – Page structure and content
- CSS3 – Styling and responsive layouts
- JavaScript – Application logic, input validation and interactivity
- JSON – Storing and reading module and assessment information

## How It Works

The application brings together different aspects of university study planning in one place.

Students can view their upcoming deadlines, organise revision tasks and record the marks they receive throughout the academic year.

The grade-tracking feature uses assessment weightings to calculate module results, allowing students to monitor their progress towards their chosen grade goal.

The application also includes a focus timer to help manage study sessions.

## Running the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension if required.
4. Start using the study planner.
